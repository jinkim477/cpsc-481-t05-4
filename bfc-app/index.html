Baking for a Cause

Every screen of the Guest User prototype as plain HTML and CSS. Each page is a 390 × 844 phone screen; on a real phone it fills the viewport.

Start at the login screen →

Entry

  • Login“Sign in” shows the guest-only message, “Continue as guest” enters the app.

Main tabs

  • AnnouncementsPosts, like and save, notifications bell, “+” create menu.
  • RecipesLive search and difficulty / time / dish filters.
  • ForumsSearch, ask a question, delete and undo your own.
  • RegistrationSign up for the club, register for events.
  • ProfileOpened from the person icon in the header.

Recipes

  • Rosemary FocacciaRecipe detail.
  • Brown Butter CookiesRecipe detail.
  • Saved RecipesEmpty state.
  • Share RecipeSix steps with validation, photo upload, preview, success.
  • View shared recipeShows the recipe you just shared (or the design’s sample).

Forums

  • DiscussionPost an answer, thumbs up / down, reply note.
  • Ask a QuestionValidation, anonymous option, “Question Shared!”.

Registration

  • Club MembershipDetails → payment → “You’re a Member!”.
  • Event RegistrationCinnamon Roll Social sign-up.

Notes

Anything you create in the prototype (a shared recipe, a question, your membership) is kept in this browser’s localStorage only, and nothing is sent anywhere. Clear site data to start over.
